# Kurage 訪問介護・ケアマネナビ（kkaigo）

住所を入れると、近くの **訪問介護・居宅介護支援（ケアマネ事業所）・定期巡回・随時対応型訪問介護看護・
夜間対応型訪問介護** を距離順に返します。利用できる曜日・電話・サイト・運営法人つき。
市区町村ごとの公表件数と「前は載っていたのに、いまは載っていない事業所」、
さらに **運営法人ごとに、いくつ持っていて、いくつ消えたか** が出ます。

デモ: <https://kurage.exbridge.jp/kkaigo.php/>

## 置き方

PHPが動くレンタルサーバーに、この3つを置くだけです。データベースサーバーも常駐プロセスも要りません。

```
kkaigo.php
kkaigo_data/kkaigo.sqlite    ← 約48MB
kkaigo_data/.htaccess        ← Require all denied（SQLite の直読みを止める）
images/ogp/kkaigo.png        ← OGP画像（kkaigo_data 配下は拒否するので別の場所に置く）
```

必要なのは **PHP 8 と PDO SQLite** だけです。heteml をお使いの場合は、置いた階層の `.htaccess` に
`AddHandler php-script .php` が要ります（無いと PHP 5.6 で動いてエラーになります）。

`kkaigo.php` の先頭にある `$SITE`（表示名）と `$OGP`（OGP画像のURL）を、ご自分のサイトに合わせて
書き換えてください。

## 画面

| URL | 内容 |
|---|---|
| `/` | 住所から探す（`?q=住所&kind=種別&km=範囲`） |
| `/corps` | 運営法人の一覧（事業所数の多い順・名前で絞り込み） |
| `/corp/{法人名}` | 法人ごとのページ（都道府県別の内訳・事業所一覧・消えた事業所） |
| `/pref/{都道府県}` | 市区町村別の一覧・推移・消えた事業所 |
| `/city/{都道府県}/{市区町村}` | 事業所一覧（政令市は `/{区}` まで） |
| `/office/{id}` | 事業所ごとのページ |
| `/gone` | 公表データから消えた事業所（全国・都道府県別・法人別） |
| `/api?q=住所` | JSON |
| `/data/offices.csv` `/data/gone.csv` | CSV |
| `/llms.txt` `/robots.txt` `/sitemap.xml` | AI検索・検索エンジン向け |

判定は置いた場所で完結し、外部のAIやAPIには何も送りません（入力住所の座標だけ国土地理院の住所検索を使います）。

## データを新しくする

厚生労働省のオープンデータは毎年 **6月末・12月末時点** のものが公開されます。
公開ページに残るのは直近の2時点だけなので、落としたCSVは捨てないでください。

```bash
python3 scripts/fetch_kaigo.py      # CSV を落とす（対象4種別 × 公開されている全時点）
python3 scripts/build_db.py         # → kkaigo_data/kkaigo.sqlite
```

CSV は **UTF-8 BOM付き**です。訪問系とケアマネの「定員」列には 0 が入っていますが、
0人ではなく「定員という考え方が無い」という意味です。画面には定員を出していません。

## 法人を法人番号で束ねていない理由

法人番号には空欄やゆれがあります。番号で束ねると同じ法人がばらけて「何か所消えたか」を数え落とすので、
**正規化した法人名**で束ねています。そのぶん同名の別法人が混ざることがあるため、法人ページに
見つかった法人番号を全部並べ、都道府県別の内訳も出しています。

## この道具が言えること／言えないこと

| | |
|---|---|
| 言える | 公表データに載っている事業所と、その所在地・連絡先・運営法人・利用できる曜日 |
| 言える | 2時点の公表件数と、番号が公表データから消えたこと |
| 言える | 同じ法人が何か所・何都道府県に持っているか |
| **言えない** | **空き状況・受け入れの可否**（公表されていません） |
| **言えない** | **定員**（訪問系とケアマネに定員はありません） |
| **言えない** | **ヘルパーの人数・サービスの質**（公表データにありません） |
| **言えない** | **廃止したかどうか**（消えた理由は公表されていません。休止・再編も「消えた」に入ります） |

## この分野の数字の読み方

2024年12月末 → 2026年6月末の1年半で、

- 訪問介護 34,499 → 35,166（差し引き **+667**）。ただし **3,242か所が消え**、それ以上が新しく載った
- 居宅介護支援 36,488 → 36,212（差し引き **−276**）。**3,146か所が消え**、新しく載った数が届かなかった
- 訪問介護が1か所も無い市区町村 **88**、ケアマネ事業所が無い市区町村 **7**

**差し引きだけを見ても、この分野の動きは分かりません。** 市区町村ごと・法人ごとに見てください。
