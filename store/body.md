### 先に、このデータの限界を書きます

**空き状況は分かりません。** 公表データに入っていないからです。受けてもらえるかは事業所か地域包括支援センターに聞くしかありません。

**定員はありません。** 訪問介護とケアマネ事業所には定員という考え方が無く、CSVの定員列には0が入っています。0人という意味ではないので、画面に定員は出しません。

**消えた事業所が廃止したかどうかは分かりません。** 公表データから消えた、という事実だけを書いています。休止も、法人の再編で事業所番号が付け替わった場合も「消えた」に入ります。

**時点は2つだけです。** 厚生労働省が公開しているのが2024年12月末と2026年6月末の2時点ぶんのためです。半年ごとの推移は、次の公開から積み上がります。

分からないものを分かったように書かない。それがこの道具の設計です。

### 何ができるか

**住所を入れると、近くの事業所が近い順に出ます。**

| 収録しているサービス | 事業所数 |
|---|---|
| 訪問介護 | 35,166 |
| 居宅介護支援（ケアマネ事業所） | 36,212 |
| 定期巡回・随時対応型訪問介護看護 | 1,516 |
| 夜間対応型訪問介護 | 204 |

2026年6月末時点、合計73,098事業所。**緯度経度が全件そろっている**ので、住所からの距離がそのまま出ます。利用できる曜日・電話・事業所のサイト・運営法人・共生型（高齢者と障害者が一体で使えるサービス）の別も表示します。

あわせて、次のページが最初から入っています。

- **法人ページ** … どの法人が、どこに、いくつ持っていて、いくつ消えたか
- **都道府県ページ（47）** … 市区町村別の一覧表と、時点ごとの公表件数
- **市区町村ページ（1,700超）** … 事業所一覧・推移・消えた事業所。政令市と東京23区は**区ごとのページ**も
- **事業所ページ（73,098）** … 連絡先・運営法人・近くの事業所
- **CSV と JSON API** … `/data/offices.csv`、`/api?q=住所`
- **sitemap.xml・llms.txt** … 検索エンジンとAI検索の両方に向けた索引

### 差し引きだけを見ても、この分野は分かりません

| | 2024年12月末 | 2026年6月末 |
|---|---|---|
| 訪問介護 | 34,499 | 35,166（+667） |
| ケアマネ事業所 | 36,488 | 36,212（−276） |

差し引きは小さく見えます。ところが同じ1年半に、**訪問介護は3,242か所、ケアマネ事業所は3,146か所が公表データから消えて**います。訪問介護はそれ以上の数が新しく載ったので差し引きが増え、ケアマネ事業所は新しく載った数が消えた数に届かず減りました。

入れ替わりの激しさは、全国の合計では見えません。市区町村ごとに、消えた事業所の名前と法人名が一覧で出ます。

**訪問介護が1か所も無い市区町村が88、ケアマネ事業所が無い市区町村が7あります。**

### 法人を主語にした画面があります

法人ページでは、その法人について次の4つを並べて出します。

- いま公表されている訪問介護の数
- 事業所全体の数と、種別の内訳
- 何都道府県に広がっているか
- 公表データから消えた数

**消えた数だけを見てはいけません。**いまの数と並べて読みます。消えた数が多くてもいまの数がそれ以上に多い法人は、法人の再編で事業所番号が付け替わった可能性があり、サービスが無くなったという話ではありません。逆に消えた数が多くていまの数が少ない法人は、実際に撤退した可能性が高い。**どちらなのかは公表データには書かれていません。**

法人は**法人番号ではなく正規化した法人名**で束ねています。法人番号には空欄やゆれがあり、番号で束ねると同じ法人がばらけて数え落とすためです。そのぶん同名の別法人が混ざることがあるので、法人ページに法人番号と所在地を併記しています。

### なぜ要るのか

訪問介護の報酬、ヘルパーの移動時間、ケアマネの更新研修。どれも「事業所が減っている」「担い手が辞めている」ことが議論の根拠です。国はそのデータを全国ぶん公開していますが、**サービス種別ごとに分かれた35MBのCSV**で、住所からも市区町村からも引ける形にはなっていません。ましてや「どの法人が何か所閉じたか」は、2時点のCSVを突き合わせないと出てきません。

この道具は、そのCSVを住所と法人から引ける形に変えただけです。ただし、変えるときに「分からないもの」を混ぜないようにしています。

### 置き方（3分）

1. `kkaigo.php` と `kkaigo_data/` を置く
2. その階層の `.htaccess` に `AddHandler php-script .php` を書く（共有サーバーの既定がPHP5.6のことがあるため）
3. `https://あなたのドメイン/kkaigo.php/` を開く

**データベースサーバーも常駐プロセスもポートも要りません。** 必要なのはPHP 8とPDO SQLiteだけです（どちらも標準で入っています）。書き込み権限も不要です。

住所から緯度経度を出すのに国土地理院の住所検索を使いますが、つながらない環境では「取得できませんでした」と表示して止まります（「事業所がありません」とは書きません）。事業所の座標は最初からデータに入っているので、外部のジオコーディングサービスは要りません。**判定は置いた場所で完結し、外部のAIやAPIには何も送りません。**

### 更新のしかた（年2回）

厚生労働省のオープンデータは毎年6月末・12月末時点のものが公開されます。同梱のPythonを2本動かせば、新しいデータベースができます。

```
python3 scripts/fetch_kaigo.py
python3 scripts/build_db.py
```

### こんな方に

- **地域包括支援センター・相談窓口** … 近隣の訪問介護・ケアマネ事業所を距離つきで一覧にして渡せます
- **議員事務所・行政** … 自分の自治体で訪問介護とケアマネ事業所が何か所消えたのかを、事業所名と法人名つきで示せます。CSVはそのまま委員会の資料に使えます
- **介護事業者・コンサルタント** … 参入・撤退の動きを市区町村ごと、法人ごとに追えます
- **福祉系のメディア** … 法人ごとの増減をたどれます。自分の名前で公開できます（MITライセンス）
- **自治体のDX担当** … 国のオープンデータを住民が引ける形にする例として、そのまま流用できます
